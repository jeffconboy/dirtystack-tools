Privacy policy

DirtyStack tools is used only by the owner of the DirtyStack Poker YouTube channel. It is not offered to anyone else.

It uses the YouTube Data API and YouTube Analytics API to read the channel's own video statistics and to update the channel's own videos. The data is stored only on the owner's computer. It is not sold, shared or sent to anyone else.

Access can be removed at any time at myaccount.google.com/permissions.

DirtyStack tools' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
